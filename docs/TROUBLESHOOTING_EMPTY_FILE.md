# 🔍 Диагностика проблемы "File is empty or contains no text"

## Описание проблемы

Ошибка возникает, когда файл успешно загружается, но парсеры не могут извлечь из него текстовое содержимое.

## Типичные причины

### 1. 📄 Файл содержит только графику/изображения

**Симптомы:**
- Файл открывается в Word/LibreOffice
- Визуально выглядит нормально
- Но состоит только из изображений, диаграмм, фотографий

**Решение:**
- Добавьте текстовое содержимое в документ
- Или используйте OCR (распознавание текста) для извлечения текста из изображений
- См. документ `docs/ocr_example.md` для примеров OCR

---

### 2. 🔒 Файл защищен паролем

**Симптомы:**
- При открытии в Word требуется пароль
- Файл зашифрован или имеет защиту от редактирования

**Решение:**
```
1. Откройте файл в Microsoft Word/LibreOffice
2. Введите пароль
3. File → Save As → выберите формат DOCX
4. Снимите защиту: File → Info → Protect Document → Remove Protection
5. Сохраните файл и попробуйте снова
```

---

### 3. 💥 Файл имеет поврежденную структуру

**Симптомы:**
- Файл открывается с ошибками
- Word предлагает "восстановить" файл
- Размер файла необычно большой или маленький

**Решение:**
```
1. Откройте файл в Word
2. Если появляется предложение восстановить - согласитесь
3. File → Save As → DOCX (выберите новое имя)
4. Попробуйте обработать новый файл
```

**Альтернатива - онлайн восстановление:**
- https://www.officerecovery.com/word/
- https://onlinefilerepair.com/

---

### 4. 📐 Документ создан в нестандартной программе

**Симптомы:**
- Файл создан не в MS Word или LibreOffice
- Имеет расширение .docx но внутренняя структура отличается
- Может быть экспортирован из PDF, Scrivener, Google Docs с проблемами

**Решение:**
```
1. Откройте файл в Microsoft Word 2016+ или LibreOffice Writer
2. Скопируйте весь текст (Ctrl+A → Ctrl+C)
3. Создайте новый пустой документ
4. Вставьте текст (Ctrl+V)
5. Сохраните как новый DOCX файл
6. Попробуйте обработать новый файл
```

---

### 5. 🎨 Файл содержит только объекты WordArt, SmartArt, формы

**Симптомы:**
- Визуально текст присутствует
- Но это не обычный текст, а графические объекты

**Решение:**
```
1. Откройте файл в Word
2. Выделите текст внутри объектов
3. Скопируйте его в обычный текстовый формат
4. Создайте новый документ с обычным текстом
5. Сохраните и попробуйте снова
```

## Диагностика: Пошаговая проверка

### Шаг 1: Проверьте файл в оригинальном приложении

```bash
# Linux: Установите LibreOffice если нет
sudo apt install libreoffice-writer

# Откройте файл
libreoffice --writer file_156.docx
```

**Проверьте:**
- [ ] Файл открывается без ошибок?
- [ ] Требуется ли пароль?
- [ ] Есть ли текстовое содержимое (не только картинки)?
- [ ] Можно ли выделить текст мышью?

---

### Шаг 2: Попробуйте извлечь текст вручную

```bash
# Установите unzip
sudo apt install unzip

# DOCX - это ZIP архив, распакуйте его
unzip -q file_156.docx -d file_156_extracted

# Посмотрите содержимое основного документа
cat file_156_extracted/word/document.xml
```

**Что искать:**
- Если видите `<w:t>текст</w:t>` - текст присутствует
- Если только теги `<w:drawing>` или `<w:pict>` - только картинки
- Если файл не распаковывается - структура повреждена

---

### Шаг 3: Используйте альтернативные инструменты

**Вариант A: pandoc (универсальный конвертер)**
```bash
sudo apt install pandoc
pandoc file_156.docx -t plain -o output.txt
cat output.txt
```

**Вариант B: antiword (легковесный)**
```bash
sudo apt install antiword
antiword file_156.docx > output.txt
```

**Вариант C: Python + python-docx**
```bash
pip install python-docx

python3 << 'EOF'
from docx import Document
doc = Document('file_156.docx')
for para in doc.paragraphs:
    print(para.text)
EOF
```

---

### Шаг 4: Проверьте метаданные файла

```bash
# Установите exiftool
sudo apt install libimage-exiftool-perl

# Посмотрите метаданные
exiftool file_156.docx

# Обратите внимание на:
# - Creator (кем создан файл)
# - Software (какая программа использовалась)
# - Encrypted (зашифрован ли)
```

## Быстрое решение для большинства случаев

### Метод "Пересохранение через Word"

1. **Откройте файл в MS Word или LibreOffice Writer**
2. **Выберите весь текст:** `Ctrl+A`
3. **Скопируйте:** `Ctrl+C`
4. **Создайте новый документ:** `Ctrl+N`
5. **Вставьте текст:** `Ctrl+V`
6. **Сохраните:** `File → Save As → file_156_fixed.docx`
7. **Попробуйте обработать новый файл в n8n**

## Альтернативные решения

### Использование OCR для извлечения текста

Если файл содержит только изображения с текстом, используйте OCR:

```bash
# Сначала конвертируйте DOCX в PDF
libreoffice --headless --convert-to pdf file_156.docx

# Затем используйте OCR (например, Tesseract)
sudo apt install tesseract-ocr

# Извлеките текст
pdftotext file_156.pdf output.txt
```

**Или онлайн сервисы:**
- https://www.onlineocr.net/
- https://www.newocr.com/

## Известные ограничения

- ❌ Legacy форматы DOC/XLS/PPT (97-2003) не поддерживаются
- ❌ Текст в изображениях не извлекается (нужен OCR)
- ❌ Рукописный текст не распознается
- ❌ Файлы с DRM защитой не поддерживаются
- ⚠️ Очень большие файлы (>50MB) могут вызвать проблемы с памятью
